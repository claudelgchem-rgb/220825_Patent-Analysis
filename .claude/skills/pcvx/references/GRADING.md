# 신뢰도 등급 기준 (A7 전용 · 항목 단위 적용)

등급은 **특허 건 단위가 아니라 항목 단위**로 부여한다. 같은 특허라도 출원일은 '상',
등록일은 '중', 청구항 해석은 '하'가 될 수 있다.

| 등급 | 판정 조건 (모두 충족) | 보고서에서의 서술 방식 |
|---|---|---|
| **상 (높음)** | ① 특허청 공식 데이터베이스의 **원문 문헌**에서 직접 확인<br>② **서로 독립적인 2개 이상 출처**가 동일 값<br>③ 법적 상태는 오늘 날짜 기준 확인 완료 | 단정형 서술 허용 |
| **중 (보통)** | ① 신뢰할 만한 2차 집계 데이터베이스(Google Patents, The Lens 등) 1곳에서 확인<br>② 원문 대조는 미완이거나, 출처 간 사소한 표기 차이 존재 | "~로 확인된다" 수준. 반드시 등급 표시 병기 |
| **하 (낮음)** | ① 2차·3차 출처(보도자료, 기업 IR, 블로그, 논문 인용)에만 근거<br>② 또는 출처 간 값이 충돌<br>③ 또는 요약서로부터의 추정 | **단정형 서술 금지.** "~로 보이나 원문 확인이 필요하다"로만 서술하고, 무엇이 확인되지 않았는지 명시 |

## 표기와 집계 규칙

- 등급은 보고서 표의 각 항목 옆에 `[상]` `[중]` `[하]`로 표기한다.
- 워드 보고서에는 등급 색상 구분을 적용한다: 상 = 진한 녹색(`1E6B34`), 중 = 주황(`C05621`), 하 = 빨강(`C0392B`).
- 보고서 말미에 등급 분포 요약을 넣는다: 전체 항목 중 상 O%, 중 O%, 하 O%.
- **'하' 등급이 전체 항목의 30%를 넘으면** 보고서 첫 페이지에 다음 문구를 그대로 넣는다.

> 본 보고서의 상당 부분이 원문 미확인 정보에 근거하므로, 의사결정에 사용하기 전 특허 원문 및 전문가 검토가 필요합니다.

## 등급 판정 시 반드시 남길 것

각 항목마다 아래 4개를 남긴다. 하나라도 비면 G4 게이트 실패다.

1. `grade` — 상 / 중 / 하 중 하나
2. `basis` — 판정 근거 한 줄 (예: "KIPRIS 공보 원문과 Google Patents 서지가 동일 값")
3. `sources` — 실제로 열어본 출처 URL 목록 (1개 이상, '상'은 서로 독립적인 2개 이상)
4. `checked_on` — 재조회를 수행한 날짜(오늘 날짜)

## 정정 규칙

원출처와 값이 다르면 **원출처 값으로 정정**하고, 정정 이력을 근거 대장에 남긴다.
정정 이력 형식: `정정: [항목] 기존값 → 정정값 / 근거 URL / 정정일`
