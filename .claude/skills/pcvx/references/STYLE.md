# 보고서 문체 규칙 (업무 초보자 기준) — A9 필수 준수

1. **줄임말·약어 최소화.** 불가피하게 쓸 때는 첫 등장 시 반드시 풀어쓴다.
   - (예) "국제특허분류(IPC, International Patent Classification)" → 이후 "국제특허분류"로 통일. 이후에도 약어 단독 사용은 피한다.
2. **개조식 나열이 아니라 문장으로 풀어쓴다.** 표는 보조 자료이며, 표만 던져놓고 설명을 생략하지 않는다. 모든 표 앞에는 그 표를 어떻게 읽어야 하는지 2~3문장 설명을 둔다.
3. **특허 용어는 처음 나올 때 괄호로 뜻풀이를 단다.**
4. **"이것이 우리에게 왜 중요한가"를 각 절 끝에 한 문단씩 붙인다.**
5. 단정과 추정을 문장에서 구분한다. 추정에는 반드시 근거와 한계를 붙인다. 확실하지 않은 것을 확실한 것처럼 쓰지 않는다.
6. 분량 기준: 워드 보고서 본문 12~20쪽, 한 문단 4~6문장.

## 용어 뜻풀이 표준 문구 (첫 등장 시 이 표현을 사용한다)

| 용어 | 첫 등장 시 표기 |
|---|---|
| 출원 | 출원(특허청에 심사를 신청하는 행위) |
| 등록 | 등록(심사를 통과해 권리가 발생한 상태) |
| 독립항 | 독립항(다른 항에 기대지 않고 홀로 권리범위를 정하는 청구항) |
| 종속항 | 종속항(독립항을 인용해 그 범위를 좁히는 청구항) |
| 우선일 | 우선일(권리의 선후를 따지는 기준일) |
| 존속기간 | 존속기간(권리가 살아있는 기간) |
| 특허 패밀리 | 특허 패밀리(같은 발명을 여러 나라에 출원한 묶음) |
| 공개 | 공개(출원 내용이 일반에 공표되는 것, 통상 출원일로부터 18개월 후) |
| 국제특허분류 | 국제특허분류(IPC, International Patent Classification) |
| 협력적 특허분류 | 협력적 특허분류(CPC, Cooperative Patent Classification) |
| 권리범위 | 권리범위(특허가 금지할 수 있는 행위의 범위) |
| 자유실시 | 자유실시(Freedom to Operate, 남의 특허를 침해하지 않고 사업을 할 수 있는지) |

## 약어 사용 자동 검사

A9는 본문 작성 후 `pcvx/scripts/validate_report.py --check-abbrev <파일>` 을 실행한다.
검사기는 두 가지를 본다.

1. 대문자 약어(IPC, CPC, FTO, WIPO, USPTO, KIPRIS, PCT, EPO, CNIPA, JPO, PTA, PTE)가
   **첫 등장 위치에서 풀어쓰였는지** — 풀어쓰기가 없거나 약어가 먼저 나오면 반려.
2. 풀어쓴 뒤에도 **약어를 단독으로 썼는지** — 위 규칙 1의 "이후에도 약어 단독 사용은 피한다"를
   기계로 검사한다. 풀어쓴 괄호 안에 들어 있는 약어는 정상 사용으로 본다.

미달 시 해당 문장을 우리말 이름으로 고쳐 다시 검사한다.

## 초보자용 평문 해설 작성 규칙 (A5)

- 전문 용어를 쓰지 않는다. 3~5문장.
- 반드시 "이 특허가 실제로 막는 행위가 무엇인지"를 포함한다.
- 청구항 문언보다 넓게 쓰지 않는다. 문언에 없는 용도·성능·효과를 권리범위인 것처럼 쓰면 A8이 과대해석으로 반려한다.
- 신뢰도 '하' 항목에 대한 해설은 단정형을 쓰지 않는다.
